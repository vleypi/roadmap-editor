# roadmap editor

Редактор интерактивных дорожных карт. Карта загружается из JSON-файла, редактируется на холсте и выгружается обратно.

## О приложении

Приложение открывается в браузере. Им можно пользоваться онлайн или запустить на своём компьютере. Регистрация не нужна: файл обрабатывается локально и никуда не отправляется.

На главной странице загружается JSON-файл или открывается готовый пример. Карта состоит из узлов и связей между ними. У узла есть название, описание, тип, цвет, положение на холсте, прогресс и теги. Связи показывают зависимости между узлами.

Редактор открывается на отдельной странице. Узлы переносятся по холсту, добавляются через меню и соединяются друг с другом. Холст масштабируется и сдвигается, текущий масштаб сохраняется в файле. В боковой панели три вкладки: слои и связи, свойства выбранного узла, JSON с выгрузкой в файл.

## Как запустить

Онлайн приложение доступно по адресу https://roadmap-editor.vercel.app. Установка не требуется.

Локально потребуются Git и Node.js 20.9 или новее.

```bash
git clone https://github.com/vleypi/roadmap-editor.git
cd roadmap-editor
npm install
npm run dev
```

После запуска приложение доступно по адресу http://localhost:3000. Команда `npm run build` собирает production-версию, `npm run lint` запускает проверку кода.

## Структура

```
roadmap-editor/
├── app/               страницы Next.js: главная и редактор
├── components/
│   ├── Main/          загрузка файла, шапка и подвал главной страницы
│   └── Editor/        холст, узлы, связи, боковая панель, верхняя и нижняя панели
├── hooks/             логика холста, боковой панели и загрузки файла
├── store/             состояние редактора на Zustand
├── types/             типы узлов, связей и редактора
├── constants/         настройки редактора и пример карты
├── utils/             геометрия связей, положение меню, выгрузка JSON
├── next.config.ts     настройки Next.js
├── eslint.config.mjs  правила ESLint
├── tsconfig.json      настройки TypeScript и алиас @/
└── package.json       зависимости и скрипты
```
